# Inbox: messages from Chris to a running autopilot

Edit this file on GitHub (phone or browser) to steer a run without waiting for it to finish.
A running autopilot checks it every minute and acts on any change. Write the newest message at
the top, under "Latest". One-word commands:

- `STOP`: finish the current round, run the shutdown checklist and write the report.
- `PAUSE`: start no new experiments; keep the page updated; resume when this line is removed.
- `SKIP`: abandon the current experiment, record it as inconclusive and move on.

Anything else is a note: priorities, a hypothesis to try, a question. The run records the time
it picked a message up on the status page ("Inbox").
